# Spec: Phase 0 - Preparation

## 1. Goal

Prepare the repository, toolchain, and documentation structure to start implementation phases.

## 2. Scope

In scope:

- Spring Boot/Gradle project bootstrap
- docs/specs/terraform/workflows structure
- baseline CI workflow
- initial documentation

Out of scope:

- full Job API implementation
- deployment to GCP

## 3. Acceptance criteria

- [ ] repository initialized with a coherent structure
- [ ] `./gradlew test` executable
- [ ] spec template available
- [ ] initial documents present in `docs/`

## 4. Evidence

- local `./gradlew test` output
- CI run screenshot or URL
- repository tree
