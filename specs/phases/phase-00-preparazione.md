# Spec: Phase 0 - Preparazione

## 1. Goal

Preparare repository, toolchain e struttura documentale per iniziare le fasi implementative.

## 2. Scope

In scope:

- bootstrap progetto Spring Boot/Gradle
- struttura docs/specs/terraform/workflows
- workflow CI base
- documentazione iniziale

Out of scope:

- implementazione completa Job API
- deploy su GCP

## 3. Acceptance criteria

- [ ] repository inizializzato con struttura coerente
- [ ] `./gradlew test` eseguibile
- [ ] template spec disponibile
- [ ] documenti iniziali presenti in `docs/`

## 4. Evidence

- output locale `./gradlew test`
- screenshot o link run CI
- albero repository
