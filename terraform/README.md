# Terraform (Phase 8)

This directory is the flat Terraform root module for the GCP infrastructure.
It adopts the resources already used by the project and remains reusable with
a separate state against an empty target project.

## Files

- `versions.tf`: Terraform and Google provider compatibility constraints
- `providers.tf`: Google provider defaults and ADC-based authentication
- `main.tf`: resources, their relationships, and architectural rationale
- `variables.tf`: typed, validated, non-sensitive input declarations
- `outputs.tf`: non-sensitive infrastructure outputs
- `terraform.tfvars.example`: portable template for environment-specific values
- `.terraform.lock.hcl`: exact provider selection generated by `terraform init`

Terraform automatically loads a local file named `terraform.tfvars`; the
tracked `terraform.tfvars.example` is documentation and is not loaded. The
local `terraform.tfvars`, `.terraform/`, saved plans, and Terraform state must
not be committed. Secret payloads are never passed through Terraform.

The Google provider uses Application Default Credentials (ADC) from the local
environment. Authentication credentials are therefore not Terraform inputs and
no service-account JSON key is stored in the repository.

Child modules, a remote backend, and multi-environment state orchestration are
intentionally deferred beyond Phase 8.
